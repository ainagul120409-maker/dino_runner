# 🦆 Duck Run

**Duck Run** is a fun endless runner game built with Django, inspired by the classic Google Chrome Dino game. Instead of a dinosaur, you control a duck that must jump over cardboard boxes and avoid obstacles to keep running as long as possible.

The game becomes faster over time, making it more challenging the longer you survive. Try to beat your high score and see how far you can go!

---

# Features

- **Endless Running:** Keep the duck running and avoid obstacles for as long as possible.
- **Jump Mechanic:** Jump over cardboard boxes to avoid collisions.
- **Increasing Speed:** The game gradually becomes faster as you continue playing.
- **Score System:** Earn points as you survive longer.
- **High Score:** Your best score is saved in the browser, so you can try to beat your personal record.
- **Pause and Resume:** Pause the game whenever you need a break.
- **Sound Controls:** Turn the game sound on or off.
- **Simple Controls:** Easy-to-learn keyboard controls.

---

# How to Play

1. Open the game in your browser.
2. Start running with the duck.
3. Jump over cardboard boxes and other obstacles.
4. Avoid collisions to keep your run going.
5. Watch your score increase as you survive longer.
6. Try to beat your previous high score!

The longer you survive, the faster the game becomes, making it increasingly difficult to avoid obstacles.

---

# Controls

| Key | Action |
|---|---|
| `Space` | Jump |
| `Arrow Up` | Jump |
| `Arrow Down` | Duck |
| `P` | Pause or resume the game |
| `M` | Toggle sound on or off |

# How to Run the Project on Windows

## 1. Install Python

Download and install Python from the official website:

https://www.python.org/downloads/

Make sure Python is added to your system PATH during installation.

## 2. Start the Game

Run the `start.bat` file. It automatically creates a virtual environment, installs Django, and starts the development server.

## 3. Open the Application

Open your browser and visit:

http://127.0.0.1:8000/
