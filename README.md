# Duck Run

A Django-powered endless runner set in a night marsh. Jump over logs and flying obstacles, duck, pause, adjust sound, and try to beat the browser-saved high score. The game speed increases as the run continues.

## Run on Windows

1. Install Python.
2. Run `start.bat`; it creates a virtual environment, installs Django, and starts the app.
3. Open http://127.0.0.1:8000/.

Controls: Space or Up to jump, Down to duck, P to pause, M to toggle sound.
